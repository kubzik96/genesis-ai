# Decision Records Index

Этот файл содержит индекс значимых решений Genesis AI.

## Правила

- каждому решению присваивается уникальный последовательный номер;
- формат имени файла: `DR-XXXX.md` или `DR-XXXX-Short-Name.md`, где суффикс является необязательным кратким названием;
- принятые решения не удаляются;
- отменённое решение получает статус `Заменено` или `Отклонено`;
- новое решение должно ссылаться на предыдущее, если оно его заменяет.
