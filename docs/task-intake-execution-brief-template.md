# Genesis Task Intake / Execution Brief

Use this short working aid to translate an ordinary-language CEO request into a
bounded executor handoff recorded in GitHub. It is not a Specification, Decision
Record, Execution Authorization, standing authority, or second Source of Truth,
and it never silently grants a subsequent gate.
