## Endpoint

`POST /v1/executions/grok/draft-pr`

### Auth / Gate / Idempotency

- `Authorization: Bearer <BROKER_SERVICE_TOKEN>` (same as S-0002)
- Header `Idempotency-Key` required
- Body gate: `G_GROK_DRAFT_PR`
- `confirmed_at` ISO-8601 within gate TTL
- `run_id` required

### Request body (client-controlled)

```json
{
  "run_id": "string",
  "gate": "G_GROK_DRAFT_PR",
  "confirmed_at": "2026-08-12T00:00:00.000Z",
  "instruction": "short edit instruction",
  "expected_base_sha": "optional current main SHA",
  "context": {}
}
```

**Forbidden from client:** `branch_name`, `base_branch`, `commit_message`, `pr_title`, `pr_body`.

### Server-controlled

- Branch: `genesis/grok/<sanitized-run_id>`
- Base: `main` (fixed)
- File: only `MEMORY.md`
- PR: always `draft: true`
- Commit / PR title & body generated by Broker

### Hard limits (enforced on real unified-diff vs current MEMORY.md)

- Max 1 file: `MEMORY.md`
- ≤ 3 changed lines
- ≤ 2 KiB diff bytes
- UTF-8 only

### Behaviour

- Uses existing `store.executeWrite` (idempotency, hourly rate, **max 1 successful Grok op per run_id**)
- Dual base-SHA check
- Partial / indeterminate failure → authoritative `UNKNOWN` (replay blocked)
- Same Idempotency-Key + different request hash → `IDEMPOTENCY_CONFLICT` (409)

### Response (success)

```json
{
  "operation": "create_branch_commit_draft_pr",
  "branch": "genesis/grok/...",
  "commit_sha": "...",
  "pr_number": 1,
  "pr_url": "https://github.com/kubzik96/genesis-ai/pull/...",
  "draft": true,
  "path": "MEMORY.md",
  "repository": "kubzik96/genesis-ai",
  "base_sha": "...",
  "changed_lines": 1,
  "diff_bytes": 120
}
```
